# Cat Breed Gallery

This is a simple web application that displays a gallery of cat breeds.

## Running the project

1. Install the dependencies:
   ```bash
   npm install
   ```
2. Start the server:
   ```bash
   node server.js
   ```
3. Open your browser and navigate to `http://localhost:8080`.

## Technologies Used

* Node.js
* Express
* Express Handlebars
